# phax 0.42.0

Changes since 0.41.0: [v0.41.0...v0.42.0](https://github.com/lbdremy/phax/compare/v0.41.0...v0.42.0).

## Highlights

- **Test worlds built once** — A copy must be indistinguishable from the world the test would have built itself; only the number of git processes changes.
- **Bounded test spawns** — No test waits on a child longer than the test says, and no child ends without the test saying who ended it.
- **Positioning: verified delegation, one name and two pitches** — Every sentence that says what phax is names verified delegation and claims only what a shipped page or command shows.
- **Plan parser: reading time bounded whatever the Markdown nests** — phax never hands the Markdown parser a plan whose nesting it has not bounded, and it says which line crossed the bound.

### Plan parser: reading time bounded whatever the Markdown nests

> phax never hands the Markdown parser a plan whose nesting it has not bounded, and it says which line crossed the bound.

- A plan whose blockquotes or lists nest over 32 levels gets one structure error naming the line and the limit, without the long wait. `phax plans lint`

  Now:

  ```text
  $ phax plans lint deep-plan.md
  deep-plan.md: 1 error, 0 warnings
  error    structure    -         line 1: blockquotes and lists nest over 32 levels deep
  $? = 1
  ```

  <details>
  <summary>Before</summary>

  ```text
  $ phax plans lint deep-plan.md        # tens of seconds of CPU
  deep-plan.md: 3 errors, 0 warnings
  error    structure    -         missing top-level "# " heading for run title
  error    structure    -         missing "## Required commands" section
  error    structure    -         no phase headings found
  $? = 1
  ```

  </details>

- Scripts reading the lint report see the nesting refusal as an ordinary structure finding with no phase. `phax plans lint --json`

  Now:

  ```text
  "findings": [
    { "severity": "error", "check": "structure", "phase": null,
      "message": "line 1: blockquotes and lists nest over 32 levels deep" }
  ]
  ```

  <details>
  <summary>Before</summary>

  ```text
  "findings": [
    { "severity": "error", "check": "structure", "phase": null,
      "message": "missing top-level \"# \" heading for run title" },
    …
  ]
  ```

  </details>

- phax run refuses a plan nested over 32 levels at once, naming the line, instead of parsing for seconds and falling back to a model extraction. `phax run`

  Now:

  ```text

  $? ≠ 0
  ```

  <details>
  <summary>Before</summary>

  ```text

  …
  ```

  </details>
