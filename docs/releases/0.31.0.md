# phax 0.31.0

Changes since 0.30.0: [v0.30.0...v0.31.0](https://github.com/lbdremy/phax/compare/v0.30.0...v0.31.0).

## Highlights

- **Protected paths: files no phase of a run may change** — A phase never lands a change to a file that decides whether its own work passes; what it cannot fix stays failing and reaches the operator.

## Upgrading

- **Records readers: `security.json` is version 3.** Every phase's `security.json` carries a required `protectedPaths`, between `skillEditGrants` and `providerSkippedForSecurity`: `null` when `phax.json` declares none, otherwise `{ globs, enforcement }` with `enforcement` one of `enforced`, `partial` or `commit-check-only`. phax reads version 1 and 2 files as version 3.
- **Records readers: `gate-attribution.json` is stamped 0.31.0.** It carries a required `protectedPaths`: `null`, or `{ result, changes }` (a `pass` with no change, or a `fail` with at least one `{ path, kind, entry }`). 0.26.0 documents and older still read, as `null`. An older `@lbdremy/phax-schemas` cannot read 0.31.0 attributions.

## What's new

### Protected paths: files no phase of a run may change

> A phase never lands a change to a file that decides whether its own work passes; what it cannot fix stays failing and reaches the operator.

- A project lists, in phax.json, the files whose change is the operator's decision, and no phase of a run may land a change to them. `phax.json protectedPaths`

  Now:

  ```text
  {
    "version": 1,
    "gateProfiles": {
      "default": [{ "command": "steme audit" }]
    },
    "protectedPaths": ["**/steme.baseline.json"],
    "security": { "profile": "secure" }
  }
  ```

  <details>
  <summary>Before</summary>

  ```text
  {
    "version": 1,
    "gateProfiles": {
      "default": [{ "command": "steme audit" }]
    },
    "security": { "profile": "secure" }
  }
  ```

  </details>
