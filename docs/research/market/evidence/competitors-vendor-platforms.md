# Vendor-owned and cloud "autonomous coding agent" platforms as competitors or substitutes of the subject tool

Research date: 2026-11-25. All sources accessed 2026-11-25. Scope: what vendors and funded startups give users natively for "delegate a change and trust the result", compared with the subject tool (local, Apache-2.0, vendor-neutral "verified delegation" CLI).

How to read the evidence:

- **Read mode.** `D` = I read the page's raw text directly (vendor Markdown docs fetched and read line by line); quotes are verbatim. `S` = the page was opened through a fetch tool that returns an extraction; text inside quotation marks is what the tool reported as verbatim, text marked "paraphrase" is the tool's wording, not the source's. `SR` = search-result snippet only, **the source was not opened** (blocked, paywalled or not reached); treat as unverified leads.
- **Dates.** Live documentation pages carry no publication date ("undated, live docs"); they describe the product as served on 2026-11-25.
- **Staleness.** Anything published before 2025-11-25 is flagged "STALE (>12 months)".
- Vendor statements are labelled vendor-claimed; independent studies and news are labelled as such.

### Independent evidence on output quality

- **E-PLAT-98** — "Where Do AI Coding Agents Fail? ## Platform profiles

### Anthropic — Claude Code, Claude Ship, Managed Agents

- **Delegation and isolation.** Claude Code runs locally with an OS-enforced sandbox around shell commands only (file tools, MCP servers and hooks run outside it) (E-PLAT-15). Cloud sessions run in an isolated Anthropic-managed VM, or on a self-hosted environment in public beta for Team and Enterprise, and are started from browser, mobile, desktop or `claude --cloud` (E-PLAT-04, E-PLAT-01). Scheduled tasks (formerly routines, research preview) fire cloud sessions from a schedule, a GitHub event or an HTTP `/fire` call (E-PLAT-03). Claude Code also runs inside GitHub Actions on `@claude` mentions, with either a subscription token or an API key (E-PLAT-17). Projects (public beta on Pro, Max and Ultra, not Team or Enterprise) let one conversation start a cloud thread per task (E-PLAT-20).
- **Verification before the human sees the result.** The cloud-session documentation describes result review through a diff view and PR creation, and an auto-fix loop that reacts to CI failures and review comments; it does not describe a platform gate that must pass before the session reports completion (E-PLAT-04). Deterministic enforcement is available but user-built: hooks are shell commands that "always happen rather than relying on the LLM", and a Stop hook is overridden after eight consecutive blocks (E-PLAT-07). Agent-team `TaskCompleted` hooks can block a task from being marked complete with exit code 2 (E-PLAT-05). `/goal` keeps Claude working "until a completion condition holds" (E-PLAT-01).
- **Review (maker/judge).** Managed Code Review uses several agents plus a verification step, reads the diff without building or running the code, and by itself neither approves nor blocks; its check run never concludes as a failure (E-PLAT-02). Ultrareview (research preview) runs a fleet of reviewers in a cloud sandbox and reports findings that are "independently reproduced and verified", billed to usage credits (E-PLAT-16). PR Steward (public beta, Team and Enterprise) pushes fixes for failing checks, conflicts and review comments and is designed not to approve or merge (E-PLAT-11). Claude Approvals (public beta, Team and Enterprise) is a policy file in the repository that sets human seats per path and where Claude may approve; it blocks merges only when made a required GitHub check, and its conditions cannot read CI results (E-PLAT-09). Anthropic's own docs warn that some policies let a bot-written PR merge with no person having looked (E-PLAT-09, E-PLAT-10).
- **Plan and scope.** Plan mode proposes a plan without editing source, and the documented pattern is to commit the plan file and ask a cloud session to execute it (E-PLAT-04). Ultraplan (early preview, April 2026) drafts and reviews plans in the cloud (E-PLAT-01). Agent-team plan approval is automatic unless the teammate's mode was changed (E-PLAT-05). No opened page describes checking the finished change against the plan or reconciling planned versus touched files; push scope is delegated to GitHub branch protection (E-PLAT-03).
- **Orchestration.** Dynamic workflows run up to 1,000 subagents per run from a script, can apply adversarial cross-review, and allow no mid-run user input (E-PLAT-06). Agent teams are experimental, with documented failure modes: lagging task status, a lead that declares the team finished early, and same-file overwrites (E-PLAT-05).
- **Cross-vendor.** Managed Agents lists only Claude models (E-PLAT-12). Cloud sessions are unavailable when Claude Code is configured for Bedrock or another third-party provider (E-PLAT-04). Code Review chooses the Claude models itself (E-PLAT-02).
- **Records and ownership.** Cloud session history lives on claude.ai and can be permanently deleted by the user (E-PLAT-04). Managed Agents keeps the event history server-side until deleted (E-PLAT-12). Local checkpoints are kept for the 100 most recent prompts and swept after about 30 days (E-PLAT-13). Team task lists and workflow run scripts are stored under `~/.claude/` (E-PLAT-05, E-PLAT-06). Retention at Anthropic is 30 days or 5 years depending on the training opt-in (E-PLAT-18).
- **Programmatic interface.** `claude -p --output-format json` returns `total_cost_usd` and a per-model breakdown; the Agent SDK exposes the same loop in Python and TypeScript (E-PLAT-14). Managed Agents exposes `/v1/agents`, `/v1/sessions`, `/v1/environments` in beta (E-PLAT-12).
- **Pricing and friction.** Pro $17–20, Max $100, Ultra $200, Team $20–125 per seat, Enterprise $20 per seat plus API-rate usage (E-PLAT-08). Cloud sessions, scheduled tasks and workflows draw on the same subscription limits (E-PLAT-04, E-PLAT-03, E-PLAT-06), while Code Review, Ultrareview and Approvals bill separately to usage credits (E-PLAT-19, E-PLAT-16, E-PLAT-09). In August 2026 Anthropic confirmed a net 17% reduction of then-current weekly limits (E-PLAT-21); earlier 2026 limit complaints are unverified leads (E-PLAT-23).
- **Scale.** Claude Code reportedly passed $2.5B annualized revenue by February 2026 and Anthropic claimed a $47B run-rate in May 2026 (vendor-claimed via secondary source) (E-PLAT-22).

### OpenAI — Codex

- **Delegation and isolation.** Codex Cloud gives each task its own workspace on OpenAI-managed, VM-backed sandboxes and connects to GitHub or GitLab repositories (E-PLAT-26, E-PLAT-34). Hooks can "run a custom validation check when a chat turn stops, enforcing standards" (E-PLAT-31). No opened page describes a platform-enforced gate on completion.

### GitHub — Copilot cloud agent, Agent HQ, code review, agentic workflows

- **Delegation and isolation.** Copilot cloud agent researches, plans and implements in the background in a cloud sandbox or Actions runner, with internet access restricted by a firewall (E-PLAT-40, E-PLAT-41). It works on one branch and one PR per task, on GitHub-hosted repositories only (E-PLAT-40).
- **Verification.** By default the agent runs CodeQL, dependency advisory checks and secret scanning, and gets "a second opinion on its code with Copilot code review" before completing the PR; these tools can be disabled (E-PLAT-41). It can run tests and linters (E-PLAT-40). GitHub states that "Logs do not replace your own review and testing" (E-PLAT-40).
- **Enforced controls.** The platform itself prevents the agent from marking its PR ready, approving or merging; blocks the requesting user from approving; holds Actions workflows until a human approves; and restricts pushes to a `copilot/` branch (E-PLAT-41). This is the strongest platform-enforced human gate found, and it is a review gate, not a test or plan gate (E-PLAT-41).
- **Review.** Copilot code review does not count toward required approvals and costs AI credits (about $0.25 to $10 per review); merge gating exists through Code Quality rulesets (E-PLAT-43).
- **Cross-vendor.** Claude and Codex run as third-party agents inside GitHub for all paid Copilot plans since February 2026, still labelled public preview in the last announcement opened (E-PLAT-44). Agentic Workflows (GA 2026-10-28) default to Copilot but accept another coding agent (E-PLAT-45).
- **Records and governance.** Commits are signed, co-authored by the requester, and link to session logs; session logs and audit-log events are available to administrators (E-PLAT-41). The Agent Control Plane (GA February 2026) centralizes enablement, policy and audit logging (E-PLAT-44). Records live on GitHub, not in the repository (E-PLAT-41).
- **Spec tooling.** Spec Kit is an open-source toolkit and was not opened in this session (E-PLAT-48).
- **Pricing.** Pro $10, Pro+ $39, Max $100, Business $19, Enterprise $39 per seat, metered in GitHub AI Credits (E-PLAT-42).
- **Scale.** GitHub reports more than 40% of PRs in September 2026 started with a detectable agent's first draft (about 110 million), up from 17% in March, with 90% merged within two weeks versus about 86% for non-agent PRs (vendor platform data) (E-PLAT-46). The merge rate measures acceptance, not quality, and the detection error rate is unpublished (E-PLAT-47).
