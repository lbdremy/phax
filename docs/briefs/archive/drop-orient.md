Write the phax spec `drop-orient`: a hard drop of the `orient` provider. phax stops querying an orientation provider at phase start, stops weaving an orientation section into the first prompt, and loses the `phax orient` command and every file, key, grant and event that exists for it. Nothing replaces it in this spec. The brief, which is designed again from the agent's need, is spec `brief-replaces-orient` and is built later on the green field this leaves.

Decided by the author on 2026-10-06. Write each into §9 as a decided question, giving its options and losses, and do not reopen any of them:
- **The removals come first.** `drop-orient` and `drop-gate-scopes` land before `gate-request` and the brief (NEXT_STEPS.md §"Before steme's audit"). This spec takes over the retirement half of the approved spec `brief-replaces-orient` (`docs/specs/2610051526-brief-replaces-orient.md`), which is then edited to be purely additive. Do not edit that spec here.
- **A hard drop.**
  - No project configures `orient`: phax, steme-lab, phax-cockpit and louloupapers were checked on 2026-10-05, and `examples/hello-world/orient.mjs` is phax's own example. So nothing eases the removal: no shim, no migration, no dedicated refusal or message, no deprecation, no alias from `phax orient` to anything, no "removed" section or upgrade note in the README, and no reading of `orient-brief.json` files written by earlier releases.
  - After the change, `orient` and orientation appear nowhere in phax's contracts, code paths, tests or docs, except where history is kept on purpose: archived specs and plans, the git history, and records already written.
  - No requirement or acceptance criterion may name a leftover `orient`, whether as a config key, a command, or a file in a phase folder. Once dropped, the key is unknown like any other, so the existing unknown-key refusal of the config layers (exit 2) applies unchanged. An unknown command gets the CLI's ordinary unknown-command error. Neither is restated or tested for `orient`.
- **Nothing replaces it here.** A phase's first prompt simply has no orientation section. The `brief` is a separate, later spec.
